# MirTechHub

## Notes & Software Marketplace

## 📖 Overview

This project is a full-stack web application designed to manage digital notes and software products in a structured and user-friendly way. It focuses on clean architecture, real-world CRUD operations, and scalable backend–frontend integration.

## 🛠️ Tech Stack

### Frontend
- Angular
- TypeScript
- HTML
- CSS
- Bootstrap

### Backend
- ASP.NET Core Web API
- Entity Framework Core
- Unit of Work & Repository Pattern

### Database
- SQL Server
